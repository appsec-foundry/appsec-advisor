update-threat-model — how to update an existing threat model

  This command only explains the update path; it never dispatches an agent or
  changes run state.

  Re-analyze only changed components and carry the rest:

    /appsec-advisor:create-threat-model
    /appsec-advisor:create-threat-model --incremental

  Reassess every component while preserving prior history:

    /appsec-advisor:create-threat-model --full

  Start from a clean model and allow IDs to be reassigned:

    /appsec-advisor:create-threat-model --full --rebuild
