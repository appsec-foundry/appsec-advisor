# Retrieval and persistent context

Apply this lens to evidenced retrieval, ingestion, or persistent model context. A vector dependency is a discovery lead, not proof of RAG, a weakness, or autonomy. Trace source → ingestion → chunks/index → retrieval/cache → model context and any memory write. Reuse component-local source slices; perform a bounded escape only for a specific unresolved control.

| Signal and trigger | Inspect and required evidence | Exclusions and classification |
|---|---|---|
| A caller can retrieve documents into model context | Trace the initiating identity, tenant and source-document ACL through the query and cache key. Check same-tenant unauthorized documents, cross-tenant access and revoked access to derived chunks. Cite the query/filter and context insertion, not only the answer formatter. | A verified upstream ACL or storage policy can satisfy the control. Output redaction does not authorize retrieval. Unauthorized reads: Information Disclosure, CWE-862 or CWE-863, LLM08 when the LLM path is proven. |
| Untrusted content enters an index or persistent memory | Inspect authorization for creation, replacement and deletion; source identity and provenance; reuse after summarization; removal of poisoned entries and dependent caches. Cite the write and later consuming context. | User-owned isolated notes are not shared poisoning. Content cannot declare its own trust or permissions. Unauthorized modification: Tampering, CWE-862/863; instruction promotion into an LLM: CWE-1427, LLM01/LLM04 as evidenced. ASI06 requires an agentic reuse path. |
| A retrieved document influences a model-selected action | Trace the document's writer, context insertion, action selection and executing authorization check. Distinguish knowledge content from policy. | A retrieved instruction alone proves no unauthorized action. Independent tool authorization and isolation limit impact. Use the agentic lens only when selected; record the supported STRIDE mechanism without inventing ASI tags. |

Severity follows demonstrated data sensitivity, reach, attacker prerequisites and existing policy caps. An unknown external-store policy is unverified, not a confirmed missing control. Corrective verification must show denied content never enters model context, including after revocation and cache reuse. No live document extraction, external fetch or target execution is authorized by this lens.
